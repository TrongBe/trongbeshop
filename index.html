Phòng thực hành SQL & Phân tích dữ liệu

tronex_sandbox.sql (AlaSQL Engine)
SELECT shop_id, COUNT(order_id) AS total_orders
FROM orders
WHERE status = 'COMPLETED'
GROUP BY shop_id
ORDER BY total_orders DESC LIMIT 5;
shop_id total_orders
SHOP_102 142
SHOP_088 97
  • ✓ Thực thi SQL trực tiếp: Chạy truy vấn tức thời trên trình duyệt với engine AlaSQL trong-bộ-nhớ, không cần cài đặt SQL Server.
  • ✓ Dữ liệu giao dịch thực chiến: Thực hành trên bảng orders, buyer_profiles cài cắm 10% dữ liệu nhiễu doanh nghiệp.
  • ✓ Cẩm nang tra cứu cú pháp: Tích hợp sẵn hướng dẫn từ cơ bản (WHERE, GROUP BY) đến nâng cao (CASE WHEN, JOIN).
  • ✓ AI Mentor & SQL Lead: Tự động kiểm tra logic dữ liệu, review Clean Code và chấm điểm chi tiết trên thang điểm 100.
